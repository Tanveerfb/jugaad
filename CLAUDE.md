## Architecture — the patterns that are load-bearing here

- **The app and the worker share state only through `WorkbenchStore` (`src/lib/data/`).** No
  SQL outside it, no second channel (owner's choice). Job statuses change only through the
  lifecycle in `src/lib/domain/job-lifecycle.ts`.
- **The app binds to 127.0.0.1** (`-H` in the scripts). That is what the §AI exception in
  `conventions.md` rests on — never remove it.
- **Every model call goes through `getAi()` in `src/lib/ai/`.** Nothing else imports `ai` or
  a provider. The default is the mock; `JUGAAD_AI_PROVIDER` switches to a local server
  (`environment.md`).
- **Structured model output is validated against the call's own approved list**
  (`fileClassificationSchemaFor`), retried once, then an `AiTaskError` — never used
  half-valid. Keep the JSON shape stated in the prompt too: Ollama 0.23 + qwen3.5 drops the
  response schema when reasoning is off (`decisions.md`).
- **Module tiles and module views share a `<ViewTransition name="module-<id>">`.** Renaming
  one side silently kills the hexagon-to-panel morph. Direction comes from
  `Link transitionTypes` (`module-open` / `module-close`), styled in `globals.css`.
- **Motif shapes come from `clip-path`**, which removes CSS borders and outside focus outlines
  at the cut corners — so edges and focus rings are inset box-shadows (`shadow-[inset_…]`),
  and hex tiles show focus on their SVG edge. A plain `border` or `outline` on a clipped
  element looks broken at the corners.
- **Theme is `<html data-theme>`, dark by default.** Use the `light:` / `dark:` variants;
  never read the theme in React state for rendering (hydration mismatch).

## Codebase conventions

- Motif primitives in `src/components/motif/`, listed in `components.md`.
- Pure logic (no React) in `src/lib/` and `src/lib/domain/`, with `*.test.ts` beside it.
- Zod schemas in `src/schemas/`; domain types are inferred from them.

## Things to avoid

- **Forcing a read of a locked file or a OneDrive online-only placeholder.** Reading a
  placeholder triggers a download; a locked file is retried later, never forced.
- **Capitals-only renames in a single step.** Windows is case-insensitive — rename via a
  temporary name, for the app's own moves as much as for `git mv`.

## Known non-blocking issues

- `npm install` warns that `unrs-resolver` has an install script not covered by
  `allowScripts`. It comes from `eslint-config-next`; harmless until approved or not.
- In `next dev`, the first navigation to a not-yet-compiled route can show "Transition was
  aborted because of timeout in DOM update" — Turbopack's on-demand compile outlasts the
  browser's view-transition timeout. Dev only; production routes are prebuilt.
- In Claude Code's Bash tool, `cd` can fail with fnm's "can't find the necessary environment
  variables" — use `builtin cd`.
- **`next dev` sometimes serves a stale `globals.css`** after edits (seen twice, 2026-10-09):
  new tokens read empty, or the server and client render different components. Restart
  the dev server before debugging styles.
- **A `@keyframes` block with only unitless SVG lengths is dropped by the CSS compiler** —
  `stroke-dashoffset: 100` vanished, `100px` survived. Give SVG lengths in keyframes a unit.
  Keyframes inside `@theme` are emitted only when an `--animate-*` variable names them;
  ones used from inline styles live outside `@theme`.
